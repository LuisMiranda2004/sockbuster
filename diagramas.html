Vista de Procesos

Flujo dinámico del proceso de compra (RF02): del carrito al pedido confirmado.

sequenceDiagram
actor Cliente
participant UI as Interfaz Web
participant API as API REST
participant BD as Base de Datos
Cliente->>UI: Agrega calcetines al carrito
Cliente->>UI: Presiona Checkout
UI->>API: POST /pedidos (HTTPS)
API->>BD: Verifica stock
BD-->>API: Stock OK
API->>BD: Guarda pedido y descuenta stock
API-->>UI: Resumen con ID de pedido
UI-->>Cliente: Confirmación del pedido
