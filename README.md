# Sockbuster Video & Socks

Prototipo web y documentación de arquitectura (Paradigma 4+1 de vistas UML) para la tienda de calcetines temáticos Sockbuster.

**Sitio web publicado:** https://LuisMiranda2004.github.io/sockbuster/



## Contenido
- `index.html`: presentación de la marca e integrantes
- `catalogo.html`: catálogo interactivo con filtros
- `diagramas.html`: vistas Lógica, Desarrollo, Procesos, Física y Escenarios (Mermaid)
